# 化竞组卷网 · ChemDrill

**化学竞赛专题题库 · 按专题组卷 · 专项练习**

在线站点：https://michael-leee.github.io/OlympiadChem-Drill/

这是一个面向化学竞赛学习者的开源题库工具。它把历届竞赛与模拟试题按九个专题重新整理，支持在线读题、按条件检索、下载单题或整卷 PDF，以及按知识点智能组卷做专项练习。

题库的结构化正文、公式、结构与谱图都从原始 PDF 提取并逐题校对，不使用 AI 生成或重绘化学结构；原始文件保持不变。

---

## 题库现状

- **2341 道完整大题**，来自第 32～40 届中国化学奥林匹克及联赛、化英社第 40 届夏季模拟试题等 22 份题源。
- 九个专题：有机化学、高分子化学、晶体化学、无机综合与结构推断、方程式与元素化学、热力学与化学平衡、电化学、动力学、分析化学。每道大题归属于一个主专题。
- 每个专题提供累计题目册与答案册的 PDF 下载；整册保留原卷字体、结构式、评分标注与来源。
- 每道题都有独立编号、来源届次与试卷、可展开的参考答案，以及从原卷裁出的配图。

题库的完整性与来源核对记录见 `data/audit_report.json`。

## 网站功能

- **按目录找题**：专题 → 届次 → 试卷 → 题目，逐级展开，也可输入专题题号直接跳转。
- **搜索**：按题目标题或题干关键词检索，可限定专题、届次、试卷；支持多关键词与化学式上下标。
- **下载**：单题 PDF、整卷 PDF、专题题目册与答案册；“按题目/试卷选题”支持勾选跨卷组合，生成自选组卷 PDF。
- **AI 组卷**：按细知识点选取已有大题，支持候选确认、题量与来源筛选、删题、单题替换。知识点来自对题干与答案的预先分析；默认只用已分析过的题目，不把检索结果宣称为全库结果。相关文档见 `docs/ai-paper.md`、`docs/deepseek-deployment.md`。
- **个人功能**：收藏、组卷历史、题目讨论等（需登录）。

首页的“写在前面”说明了建站缘起与题库使用建议。多数原图内部文字未做 OCR，因此不能直接检索图中文字。

## 欢迎贡献题目

题库靠大家完善。如果你手上有题源（竞赛真题、模拟卷、专题练习），欢迎提交给维护者审核后合入。**所有投稿都需要经过人工审核才会进入仓库和网站**，审核重点包括：题源清晰、题目与答案配对正确、图像完整、版权与来源标注得当。

### 方式一：提交 Issue（推荐，无需写代码）

1. 在本仓库新建一个 Issue，标题写清楚题源，例如：`投稿：第 XX 届 XX 模拟卷（题目 + 答案）`。
2. 在 Issue 里说明：
   - 题源名称、届次/年份、试卷数量；
   - 题目 PDF 与参考答案 PDF（可上传附件，或给出可下载的链接）；
   - 是否已有电子版答案、是否有特殊排版需注意。
3. 维护者会在 Issue 中确认收到，并完成审核与入库；结果会在该 Issue 下回复。

### 方式二：提交 Pull Request（适合熟悉 Git 的同学）

1. Fork 本仓库，新建分支。
2. 将题目 PDF 与答案 PDF 放到 `sources/` 下，命名包含届次与卷名。
3. 按现有专题体系核对每道题的主专题；参考 `docs/ingestion40.md` 与 `add_questions.py` 的用法。
4. 本地跑通构建与校验后提交 PR，在 PR 描述里列出：新增题源、题目数量、专题分布、已做的检查。
5. 维护者审核通过后合并；未通过的 PR 会说明原因，欢迎补充材料后重开。

### 审核与收录标准

- 题目与答案必须成对、编号一致，图像（结构式、谱图、表格）清晰完整。
- 每道大题只归一个主专题；分类有疑问时以题干核心考点为准，可在投稿时注明建议专题。
- 来源与版权信息明确；仅用于学习交流，不用于商业用途。
- 维护者保留最终审核与调整权。审核通过后由维护者统一入库、重建题库并发布站点。

## 本地预览

仓库需在同一目录保留 `dist/` 下的网页与数据。用本地 HTTP 服务预览：

```bash
cd dist
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。直接双击 HTML 文件无法读取题目 JSON，必须通过 HTTP 服务访问。

仓库 `main` 分支更新后，GitHub Actions 会自动把 `dist` 发布到 GitHub Pages。为控制 Pages 产物体积，整册 PDF 通过 raw.githubusercontent 链接提供下载，不打包进 Pages 站点。

## 技术说明

- 网页正文与表格为 HTML，行间公式用 KaTeX 离线渲染；图形按原 PDF 的坐标从无水印副本裁切，并按阅读顺序插回文字流。
- 题库数据分为 `questions.json`（元数据）与 `presentation.json`（正文与答案），避免重复下载；数据文件带版本参数，内容更新时同步升级版本号以刷新浏览器缓存。
- 关键脚本：`add_questions.py`（新题入库）、`stages/`（解析、裁切、重建、发布各阶段）、`render.py`（正文渲染）。
- 环境依赖见 `requirements.txt`；本地组卷服务相关见 `server/` 与 `supabase/`。
